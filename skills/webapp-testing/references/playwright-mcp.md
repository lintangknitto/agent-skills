# Playwright MCP — Tool Reference (on-demand)

Load file ini hanya saat butuh detail tool Playwright MCP.

## Tools utama
- `playwright_browser_navigate(url)` — buka URL
- `playwright_browser_snapshot` — capture accessibility tree
- `playwright_browser_click(target)` — klik elemen
- `playwright_browser_type(target, text)` — isi input
- `playwright_browser_take_screenshot` — ambil screenshot
- `playwright_browser_console_messages(level)` — ambil log console
- `playwright_browser_network_requests` — daftar network requests
- `playwright_browser_evaluate(function)` — jalankan JS di page

Lihat skill `e2e-testing` untuk Page Object Model dan strategi flaky test.
